# Conecta Bancaribe V4.6

V4.6 completa la experiencia del solicitante sobre el motor interno BRM ValueFlow.

Flujo visible: Registrar necesidad → Mis Necesidades → Seguimiento → Información adicional → Decisión/entrega → Aceptación → Valor.

El usuario de negocio trabaja con lenguaje simple. RELATE, SHAPE, READY, COMMIT, capacidad, comités y demás controles permanecen en la experiencia BRM.

## Compatibilidad
La migración es no destructiva y compatible con la base V4.5.2. Al iniciar, se crea únicamente `need_updates` si no existe. No ejecutar `npm run seed` si se desea conservar la data histórica.
